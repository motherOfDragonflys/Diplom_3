# UI Тесты для сервиса Stellar-Burgers
## Структура классов  
**src/main — Page Object'ы, модель данных и утилиты**  

- **src/main/java/model**
  - `User` — POJO пользователя: имя, email, пароль; используется и в UI-тестах, и в запросах к API.
- **src/main/java/pageobjects**
  - `BasePage` — базовый класс страниц: общие методы ожиданий и действий  
  - `HeaderPage` — элементы шапки: переходы через «Конструктор», «Личный кабинет».  
  - `ConstructorPage` — конструктор бургера: вкладки «Булки»/«Соусы»/«Начинки», кнопка «Войти в аккаунт» / «Оформить заказ»  
  - `LoginPage` — форма входа, ссылки на регистрацию и восстановление пароля.  
  - `RegisterPage` — форма регистрации, проверка ошибки валидации пароля.  
  - `ForgotPasswordPage` — форма восстановления пароля, ссылка «Войти» под формой.  
- **src/main/java/utils**  
  - `ApiEndpoints` — константы эндпоинтов API (создание, логин, удаление пользователя).  
  - `BrowserFactory` — выбор браузера по параметру запуска, общие настройки драйвера.  
  - `Config` — базовый URL и сборка адресов страниц и эндпоинтов.  
  - `TestData` — генерация тестовых данных: уникальный email, имя пользователя, граничные значения пароля.  

**src/test/java — автотесты**  

- **src/test/java/base**  
  - `BaseTest` — настройки браузера для UI-тестов: запуск, `Before`/`After` 
  - `BaseApiTest` — расширяет `BaseTest`: через API создаёт пользователя перед тестом (`@Before`), удаляет после (`@After`) по токену;   
- **src/test/java/tests**  
  - `LoginTest` — вход по четырём точкам входа: кнопка «Войти в аккаунт», «Личный кабинет», ссылки из форм регистрации и восстановления пароля.  
  - `RegisterPositiveParameterizedTest` — успешная регистрация: пароль от 6 символов включительно, проверка создания пользователя через API.  
  - `RegisterNegativeParameterizedTest` — неуспешная регистрация: пароли 0–5 символов, проверка сообщения об ошибке валидации.  
  - `ConstructorSectionParameterizedTest` — переход по вкладкам конструктора: после клика активна вкладка и отображается соответствующая секция.  
- **target — отчеты Allure**
